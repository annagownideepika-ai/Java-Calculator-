# 🧮 Java Calculator

## 📌 Description

A simple **Calculator Application developed using Java** that performs basic arithmetic operations such as addition, subtraction, multiplication, division, and modulus.

This project is beginner-friendly and demonstrates core Java programming concepts.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Menu-driven calculator
- Decimal number support
- Division-by-zero handling
- Basic input validation

## 🛠 Technologies Used

- **Language:** Java
- **IDE:** VS Code / Eclipse / IntelliJ IDEA
- **JDK:** Java 8 or above
- **Concepts:** Scanner, Switch Case, Loops, Methods

## ⚙️ Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/Java-Calculator.git
```

**2. Navigate to the project folder**

```bash
cd Java-Calculator
```

**3. Compile the Java program**

```bash
javac src/Calculator.java
```

**4. Run the program**

```bash
java -cp src Calculator
```
